# Maison Fleur

### Made of Petals & Poetry.

Maison Fleur is a custom flower bouquet ordering website where customers can create personalized bouquets using real flowers and order them for delivery.

Customers can choose their preferred flowers, specify quantities, select wrapping paper and ribbons, add a personal message, and provide delivery details. The system also provides an administrative interface for managing flowers and customer orders.

## Features

- **User Management:** Customer registration, login, and authentication.
- **Flower Catalog:** Browse available flowers and their prices.
- **Bouquet Customization:** Choose flowers, quantities, wrapping paper, ribbons, and personal messages.
- **Order Management:** Place orders with recipient and delivery information.
- **Order Tracking:** View order details and delivery status.
- **Admin Dashboard:** Manage flowers and customer orders.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** MySQL
- **Testing:** pytest, unittest.mock, Selenium
- **Version Control:** Git and GitHub

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd maison-fleur
   ```

3. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

4. Activate the virtual environment.

   **Windows:**
   ```bash
   venv\Scripts\activate
   ```

5. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

6. Configure the MySQL database.

7. Run the application:

   ```bash
   python app.py
   ```
